# LUMA — Fashion Clothing Brand E-Commerce Website

A responsive and interactive fashion e-commerce frontend website built with HTML5, CSS3, Bootstrap, JavaScript, and jQuery, with a strong focus on modern UI design, interactive shopping functionality, responsive layouts, and user-focused experiences.

The project combines Bootstrap's responsive grid system with custom CSS, JavaScript, jQuery, and LocalStorage to create a functional client-side fashion shopping experience.

## 📌 Project Overview

LUMA is a modern fashion clothing brand e-commerce frontend website designed and developed as a practical frontend development project.

The project focuses on creating a complete and interactive online fashion shopping experience rather than a simple static website.

The website includes product browsing, product search, shopping cart functionality, wishlist management, user account features, login and sign-up interfaces, settings, newsletter subscription, contact forms, Q&A, and other interactive UI elements.

A major focus of this project was making the website feel like a real-world fashion e-commerce platform by combining responsive design, interactive components, animations, hover effects, client-side data management, and user-focused navigation.

The project also uses **LocalStorage** to maintain client-side data such as cart items, wishlist products, user information, settings, and newsletter subscriptions.

## 💾 Client-Side Data Management

Since LUMA is currently a frontend e-commerce project without a backend database, **LocalStorage** was used for client-side data management.

This allows the website to maintain selected information between page refreshes.

Client-side data management is used for:

* User accounts
* Login state
* Cart products
* Product quantities
* Wishlist products
* Settings
* Currency preferences
* Theme preferences
* Notification preferences
* Newsletter subscriptions

This approach helped simulate several real-world e-commerce interactions within a frontend-only environment.
